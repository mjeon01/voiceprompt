# 비용과 자원 사용량

측정 기준일: 2026-11-16. 아래 실측은 Mac 0.4.1 / Windows 0.5.0-preview.1의 결과입니다.
0.4.2 / 0.5.0-preview.2부터 언어 자동 감지가 추가돼 처리 시간이 달라질 수 있습니다.
앱의 구조, 로컬 측정, 외부 서비스의 조건을 구분합니다.

## 사용자 비용

VoicePrompt는 무료 배포이며 계정, API 키, 구독, 결제 기능이 없습니다.
음성 인식은 기기에서 실행하므로 분당 API 비용이나 월간 서버 사용량 제한이 없습니다.
한 번의 녹음은 두 플랫폼 모두 최대 600초입니다. 장시간 회의 녹취보다는 입력창 받아쓰기를 위한 앱입니다.

앱과 모델 다운로드에 인터넷이 필요합니다. 모델이 준비되면 받아쓰기에 네트워크 요청을 하지 않습니다.
업데이트·모델 재설치 때는 다시 다운로드할 수 있습니다. 기기의 전기·배터리·저장 공간·네트워크 비용은 사용자 부담입니다.
결과를 전송하는 별도 AI 서비스의 요금은 VoicePrompt와 무관합니다.

## 저장 공간과 메모리

| 항목 | 값 | 근거와 해석 |
|---|---|---|
| Mac 기존 설치 앱 | 약 5.1 MiB | 2026-11-16 로컬 `du -sk` 측정. 공개 ZIP 및 라이선스 추가 후 크기는 다를 수 있음 |
| Mac 모델·사전 캐시 | 약 1.53 GiB | 같은 날 모델·사전 폴더 1,602,952 KiB. 빌드 캐시 제외 |
| Windows Whisper small | 487,601,967 bytes, 약 465 MiB | 배포 모델의 고정 크기와 SHA-256 검사. 앱·.NET 런타임 별도 |
| 10분 원시 오디오 버퍼 | 약 36.6 MiB | 16,000 samples/s × float32 4 bytes × 600s. 추가 복사·모델·UI 메모리 제외한 계산값 |
| Mac 샘플 추론 프로세스 최대 RSS | 217.7 MiB | 아래의 단일 공개 샘플 CLI 실측. OS·Core ML의 모든 가속기 메모리를 포함하는 수치는 아님 |
| 실제 장시간 RAM·CPU·배터리 | 보편적 실측값 없음 | 모델, 음성 길이, CPU, OS에 따라 변함. 버퍼 계산값을 앱 전체 RAM으로 해석하면 안 됨 |
| Windows 권장 여유 | RAM 8 GB 이상, 디스크 2 GB 이상 | 초기 설치·추론을 위한 보수적인 안내값이며 최소 사양 성능 검증값은 아님 |

Windows 모델 파일의 원본은 [ggerganov/whisper.cpp](https://huggingface.co/ggerganov/whisper.cpp/blob/main/ggml-small.bin)입니다.
모델 크기가 RAM 사용량과 같지는 않습니다. 설치 ZIP의 정확한 용량은 Releases에 표시됩니다.
Windows CPU 추론은 Mac의 Core ML 가속보다 미리보기가 느릴 수 있으며 실시간 속도를 보장하지 않습니다.

### Mac 단일 샘플 측정

2026-11-16, Apple M4 Pro / RAM 48 GB / macOS 27.2.1에서 공개 한국어 FLEURS 샘플 약 13.1초를
배포용 0.4.1 실행 파일과 large-v3 turbo로 처리했습니다. 기존 모델을 사용해 네트워크 다운로드 없이 실행했습니다.
0.5초씩 입력 길이를 늘리며 반복 인식하는 CLI 검사에서 미리보기 디코딩 평균 **1.18초**, 마지막 처리 **1.44초**,
모델 로드와 반복 검사를 합한 전체 경과 **33.10초**, `/usr/bin/time -l` 최대 RSS **217.7 MiB**였습니다.
이는 여러 번 같은 음성 앞부분을 재인식한 진단 작업의 결과로, 일반 받아쓰기의 전체 지연이나 실시간 처리 배수를 뜻하지 않습니다.
마이크·창·UI를 켠 전체 앱의 정상/최대 메모리나 Neural Engine/Core ML 자원 총량도 아닙니다.
표본 한 개의 결과이며 다른 기기와 장시간 작업에 일반화하지 않습니다.

### Windows 단일 샘플 측정

2026-11-16, GitHub의 Windows runner(프로세스에 제공된 CPU 스레드 2개)에서 Whisper small로 공개 영어 JFK 샘플을
처리했습니다. 모델 로드 포함 **12.36초**, 프로세스 최대 working set **830.9 MiB**였습니다.
이는 마이크·자동 입력 없이 실행한 CLI 추론 검사입니다. Windows 사용자 PC의 한국어 실시간 성능을 보장하지 않습니다.
Mac 결과와는 모델·음성·하드웨어·메모리 측정 방식이 달라 직접적인 성능 비교가 아닙니다.

현재 출시 자료에는 한국어 정확도 %, 보편적인 초당 처리량, 장시간 배터리 소모율을 제시하지 않습니다.
아직 동일한 조건에서 충분히 측정하지 않았기 때문입니다.

## 운영자 비용

| 항목 | 현재 구조 / 발생 조건 |
|---|---|
| 추론 서버·DB·도메인 | 사용하지 않음. 상시 인프라 비용 없음 |
| 공개 문서·배포 파일 | GitHub 저장소와 Releases 사용. 모델은 원 배포처에서 사용자 기기로 다운로드 |
| 비공개 소스 빌드 | 계정별 GitHub Actions 포함량 사용. 초과·추가 저장량은 요금 발생 가능 |
| 개발·QA | 두 OS 실기기, 테스트 시간, 의존성 업데이트의 실제 유지보수 비용 |
| macOS Developer ID·공증 | 현재 미적용. Apple Developer Program 가입 시 연회비 발생 가능 |
| Windows 코드 서명 | 현재 미적용. 선택한 인증서·서명 서비스에 따라 비용 발생 |

공개 저장소의 표준 GitHub-hosted runner는 무료지만 **비공개 소스를 빌드하는 작업에는 공개 저장소 무료 조건이 자동으로 적용되지 않습니다**.
이 프로젝트의 Windows 빌드는 비공개 저장소에서 수동 실행하며 20분 제한과 산출물 2일 보관을 사용합니다.
계정의 실제 청구·남은 포함량은 유지관리자가 확인해야 하며 이 문서에서 청구액 0원을 보장하지 않습니다.
[GitHub Actions 요금 정책](https://docs.github.com/en/actions/concepts/billing-and-usage).

GitHub Releases는 파일당 2 GiB 미만, 릴리스당 최대 1,000개 파일을 허용하며 총 릴리스 크기와 대역폭에 별도 한도를 두지 않는다고 안내합니다.
[GitHub Releases 제한](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases).

서명 프로그램의 조건과 가격은 바뀔 수 있어 결제 전에 공식 안내를 확인합니다.
[Apple Developer Program](https://developer.apple.com/programs/whats-included/).

## 실제 이용량을 알 수 있나요?

사용 통계를 수집하지 않으므로 활성 사용자, 사용 시간, 누적 음성 길이, 재사용률을 알 수 없습니다.
GitHub가 제공하는 다운로드 횟수는 재다운로드·업데이트·자동 다운로드를 포함할 수 있습니다.
이를 실제 사용자 수나 지속 사용률로 표시하지 않습니다.
