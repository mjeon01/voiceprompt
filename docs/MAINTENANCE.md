# 유지보수와 지원

VoicePrompt는 개인이 유지하는 무료 로컬 앱입니다. 정해진 배포 주기·응답 시간·영구 지원을 보장하지 않습니다.
현재 자동 업데이트, 사용자 계정, 원격 서버, 유료 지원 계약은 없습니다.

## 유지하기 쉬운 점과 계속 필요한 일

모델이 준비된 앱은 서버 없이 작동하므로 서버 장애·API 키 만료·분당 API 요금에 의존하지 않습니다.
모델은 앱과 별도 저장되어 업데이트 후 재사용할 수 있습니다. 다운로드가 막히면 신규 설치·재설치는 영향을 받지만
기존의 정상 모델을 이용한 오프라인 받아쓰기는 계속 가능합니다.

macOS는 Swift/WhisperKit, Windows는 .NET/Whisper.net을 사용합니다. 각 OS의 기본 입력·권한 API를 활용하는 대신
두 구현을 함께 검증해야 하며 개발 비용이 없어지는 것은 아닙니다. 의존성 버전을 고정하고, Windows는 NuGet 잠금 파일,
Mac은 SwiftPM 해석 결과를 관리합니다. 코어 전사·무음 필터·용어 보정의 회귀 검사를 유지합니다.

## 변경할 때 확인하는 항목

| 변경 | 확인할 내용 |
|---|---|
| 음성 모델·엔진 | 언어별 음성 샘플, 무음에서의 허위 문장, 모델 크기·라이선스, 실제 추론 |
| 단축키·입력 | 중복 등록, 빠른 재입력, 포커스 변경, 비밀번호 창, 취소 후 지연 결과, Enter 미전송 |
| OS·런타임 | 지원 버전, 마이크 권한, 장치 분리, 클립보드 및 접근성 API |
| 배포 | 새 설치, 업데이트, 의존성·라이선스 포함, ZIP 내용·해시, 개인 파일 제외 |
| 보안 업데이트 | 사용 중인 의존성의 보안 공지와 지원 수명 검토, 필요한 패치 재배포 |

이 표는 유지보수 절차이며 모든 항목을 이미 검증했다는 뜻은 아닙니다.
각 릴리스의 완료·미완료 항목은 [릴리스 기록](RELEASES.md)에 별도로 적습니다.
.NET 10의 지원 범위는 [Microsoft 지원 정책](https://dotnet.microsoft.com/en-us/platform/support/policy/dotnet-core)에서 확인합니다.

## 버그 제보

[GitHub Issues](https://github.com/mjeon01/voiceprompt/issues)에 OS 버전, 앱 버전, CPU 종류, 대상 앱,
재현 순서, 기대한 동작, 실제 동작을 적어 주세요. 개인 음성, 전사 원문, 계정 정보, 키·토큰을 첨부하지 마세요.
공개 제보라는 점을 고려해 민감한 문장 대신 같은 문제를 재현하는 짧은 예문을 사용하세요.
소스가 공개되지 않으므로 외부 코드 PR을 통한 기여보다 버그 재현과 문서 개선 제안을 받습니다.

## 업데이트·롤백

새 버전은 Releases에서 수동 설치합니다. 문제가 생기면 앱을 종료하고 이전 릴리스의 앱 폴더로 되돌릴 수 있습니다.
모델·설정 호환성 변경이 있다면 해당 릴리스에 별도로 표시합니다. 모델을 삭제하면 재다운로드가 필요합니다.
개발 중단 시에도 설치된 앱을 원격으로 비활성화하는 기능은 없지만 향후 OS 호환성을 보장할 수는 없습니다.
