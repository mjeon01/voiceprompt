# 음성과 데이터 처리

## 평소 사용

- 녹음은 사용자가 단축키나 녹음 버튼으로 시작한 동안만 수행합니다.
- 음성은 메모리 버퍼에서 처리하고 세션 종료·취소 시 버퍼를 해제합니다. 앱이 음성 파일을 자동 보관하지 않습니다.
- 인식 결과는 화면에 남아 복사할 수 있습니다. 다음 녹음 시작이나 앱 종료 시 사라지며 전사 이력 파일·서버 동기화는 없습니다.
- 메모리 해제는 메모리의 즉각적인 보안 삭제를 의미하지 않습니다. OS의 메모리·스왑 관리까지 통제하지 않습니다.
- 모델과 사용자 설정은 기기에 남습니다. 저장 위치와 제거법은 [사용 안내](USAGE.md)를 참고하세요.
- 자체 분석 도구, 원격 오류 전송, 광고 SDK, 계정 서버를 구현하지 않았습니다.

## 네트워크가 필요한 때

최초 모델·언어 사전을 다운로드하거나 사용자가 설치를 다시 시도하면 Hugging Face 등 모델 배포 서비스에 접속합니다.
이때 배포 서비스가 IP 주소와 일반 다운로드 메타데이터를 볼 수 있습니다. 음성·전사 내용을 요청에 넣지 않습니다.
모델이 준비된 뒤의 받아쓰기에는 원격 음성 인식 API를 호출하지 않습니다.
GitHub에서 앱을 다운로드하거나 수동 업데이트할 때는 GitHub 정책이 적용됩니다.

## 클립보드와 대상 앱

Mac 자동 입력은 전사 문장을 클립보드에 잠시 넣고 붙여넣기를 요청합니다. 다른 프로그램이 그 사이 클립보드를 바꾸지 않았으면
이전 내용을 복원하려고 시도합니다. 이미 클립보드 관리자나 OS 동기화가 읽은 내용을 회수할 수는 없습니다.
Windows 자동 입력은 유니코드 키 이벤트를 사용하므로 자동 입력 경로에서는 클립보드를 변경하지 않습니다.
두 플랫폼의 **결과 복사** 버튼은 명시적으로 클립보드에 결과를 넣습니다. OS 클립보드 기록·동기화와 다른 앱의 접근은 OS 설정을 따릅니다.

입력된 텍스트에는 대상 앱의 저장·동기화·네트워크 정책이 적용됩니다. VoicePrompt가 Enter를 누르지는 않지만
대상 앱이 입력 중인 내용을 자동 저장할 수 있습니다. 기밀 내용을 다룰 때는 대상 앱과 클립보드 설정도 확인하세요.

## 진단 자료

개발 검증에서는 공개 오디오 샘플로 파일 추론을 수행할 수 있으며, 진단 명령의 출력에는 전사 결과가 포함될 수 있습니다.
이 자료는 일반 앱 사용에서 자동 생성하지 않습니다. 공개 저장소에 개인 녹음·전사·로컬 로그를 게시하지 않습니다.
버그 제보에도 개인정보를 지운 재현 방법만 올려 주세요.
