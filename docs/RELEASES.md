# 릴리스와 검증 범위

## macOS 0.4.2 / Windows 0.5.0-preview.2

2026-11-17 영어 개발 용어 표기 수정.

- 한국어로 고정하던 인식 설정을 언어 자동 감지로 변경했습니다. 번역 대신 원어 전사를 사용합니다.
- README·GitHub·API 등 개발 용어를 인식 힌트에 추가하고 `리듬위/리드미 → README`, `깃허브 → GitHub`를 보정합니다.
- 한국어 조사와 단어 경계를 확인하며 일반 문장, 코드, URL, 실제 파일명은 유지합니다. 기능을 끄면 표기를 수정하지 않습니다.
- Mac과 Windows가 같은 35개 표기 예제를 공유합니다. 기존 검사를 포함해 Mac 코어 244개, Windows 코어 128개를 통과했습니다.
- Mac SDK 미리보기 검사 158개를 통과했습니다. 용어 힌트가 출력에 섞이지 않는지, 자동 언어 감지·전사 모드인지 확인합니다.
- Mac의 실제 추론 경로에서 합성 한국어·영어 README/GitHub/API 발화와 기존 공개 한국어 샘플을 확인했습니다. 합성 음성 검사는 실제 사용자 마이크 정확도 검증과 구분합니다.
- Windows는 계속 Preview입니다. 언어 자동 감지가 매우 짧은 발화나 모든 혼합 언어의 정확도를 보장하지는 않습니다.

## macOS 0.4.1 / Windows 0.5.0-preview.1

2026-11-16 최초 공개 배포. Windows는 최초 Preview이며 Mac과 같은 완성도를 주장하지 않습니다.

### macOS

- WhisperKit 기반 한국어 로컬 받아쓰기, 미리보기, 단축키, 입력창 확인과 붙여넣기.
- 실시간 전사에서 모델에 준 용어 힌트가 결과로 보이던 오류 수정 포함.
- 코어 회귀 검사 138개와 기존 SDK 미리보기 검사 106개의 검증 기록 보유.
- 공개 패키지의 Release 빌드·서명 무결성·ZIP 내용 검사를 통과했습니다.
- 공개 한국어 샘플 파일의 실시간 중간 결과와 최종 전사를 확인했습니다. 측정 조건은 [비용 문서](COSTS.md)에 있습니다.
- 공개 패키지는 개인 인증서 대신 임시 서명을 사용하며 Apple 공증을 받지 않았습니다.

### Windows Preview

- Windows 11 x64용 .NET 앱. .NET 런타임을 포함한 폴더형 ZIP으로 배포.
- CPU 로컬 Whisper small, 한국어 인식, SHA-256을 확인하는 모델 다운로드.
- 기본 마이크, 시작·완료 전역 단축키, 취소, 세션당 최대 10분.
- 구간 기반 미리보기, 무음 검사, LLM 용어 힌트와 제한적인 표기 보정.
- 입력 대상 확인 후 유니코드 입력, 수동 복사, 알림 영역, 로컬 설정 저장.
- 공통 로직 회귀 검사 22개, Windows x64 Release 빌드, WPF 창 구성·초기 버튼 상태, 유니코드 입력 구조 검사를 통과했습니다.
- Windows runner에서 UI 이미지를 생성하고 Whisper small로 공개 영어 JFK 샘플의 CPU 음성 추론을 확인했습니다.
- 입력 이벤트 검사는 구조 검증이며 다른 앱에 실제 키 입력을 보내는 검사는 아닙니다. 영어 샘플 통과가 한국어 실사용 품질 검증을 뜻하지 않습니다.

### 아직 확인이 필요한 것

- 실제 Windows 마이크 장치별 호환성, 한국어 장시간 정확도와 지연.
- 물리 키보드의 반복 단축키와 다른 앱의 단축키 충돌 조합.
- 브라우저·Electron·터미널 각각에서의 한글 입력과 권한 상승 앱 처리.
- 8 GB PC의 메모리, 저성능 CPU의 응답 시간, 장시간 배터리 사용량.
- 공증·정식 서명된 설치 및 OS별 신뢰 경고 없는 배포.

자동 검사·컴파일·공개 샘플 추론을 통과하더라도 위 실기기 검증을 대체하지 않습니다.
